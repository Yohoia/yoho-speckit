# 采集规范

回到 [主流程](../SKILL.md)。页面选择、采集及质量检查时读取。

## 页面选择

standard 通常3个代表页、最多5页，优先不同布局或组件家族。
输入页总在计划内；发现链接不自动扩大 plan.pages。
没有新增设计信息可提前停止，在 selectionNotes 说明。
默认同源公开页面；跨源用 authorizedOrigins 显式限定。
重定向检查最终身份；无法读取用户指定页面时说明并保留缺口。

## 观测条件

默认 desktop 1440×1000、mobile 390×844；用户指定值优先。
这些是CSS视口测量条件，不是源站断点或真实手机硬件模拟。
同一快照记录URL、视口、时间、状态、滚动位置和浏览器版本。
default 与 scroll-01/scroll-02 等滚动状态分开，避免懒加载/虚拟内容被合并。
走查最多24步；到达页尾、等待超时、未加载图片和资源失败分别报告。
动态内容可能随时间/请求改变，单次观测不证明所有状态。
hover/focus 通过 [本地浏览器](browser.md) 的同一采集入口执行。
未观察的展开、暗色、焦点或其他状态保持未验证。

## 元素、规则与字体

assets/probe.js 采集DOM计算样式、几何、伪元素、inline声明、可访问CSSOM。
空 content 的装饰伪元素有效；颜色包括可测的SVG fill/stroke。
默认最多1200项，优先标题、导航、输入和行动入口；截断明确报告。
Shadow DOM/iframe 内容未全面采样时写缺口，不宣称完整。
不读取表单值、Cookie、存储、内联脚本或令牌；导航URL过滤疑似敏感参数。

CDP保存原始样式表文本和哈希，并对代表元素采集匹配规则与渲染字体。
未进入规则/字体采样的元素仍有计算样式，但来源深度为未知。
命中规则保持 matched-candidate：匹配不等于最终获胜声明。
声明范围、URL、条件、继承和伪元素上下文用于回溯。
fontFamily是声明栈，renderedFonts才是该节点的实际字体使用记录。
计算样式px是当前解析值，源rem/变量/clamp表达保存在CSS证据中。
选择器和nodeId是本次快照坐标，不保证网站改版后稳定。
Canvas/WebGL不等于DOM样式，截图留证并说明不能逐元素测量。

## 质量与提交

先核对页面身份，再验证观察合同；挑战页不是目标页面。
完整记录未读声明、等待不足、截断、未观察状态和序列化失败。
新观察和截图验证后才更新index；失败保留成功证据和解释。
再次采集产生新内容文件，旧内容不被覆盖。
再次build产生候选，Agent合并审核后统一导出。
