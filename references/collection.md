# 采集规范

回到 [主流程](../SKILL.md)。确定范围和采集时读取。

## 页面选择

standard 通常 3 个代表页，上限 5；不凑数量。
输入页总是第一项；优先暴露不同组件或布局的同源导航目标。
商品编号或文章标题不同但模板相同，通常归同一家族。
没有新增设计信息可停止，在 plan.selectionNotes 记录原因和未访问候选。
extended 使用用户指定上限，范围大时逐批保存。
plan.pages 是执行清单；发现链接不自动扩大采集范围。
查询参数、地区版本、登录和交易入口先判断语义。
重定向核对最终身份；originalUrl 始终保留原输入。

## 页面与状态

默认 desktop 1440×1000、mobile 390×844；用户指定值优先。
这些是观测条件，不是源站断点。
滚动检查到页尾并等待字体和重要媒体，记录未加载项。
云端采集器最多走查 24 屏；没到页尾会报告 walkComplete=false。
默认状态名 default，其他状态如 nav-open、button-focus。
同一状态记录 URL、视口、主题、滚动位置与时间。
hover/focus/展开通过宿主浏览器或连接器采集。
批采集器只自动采 default，静态声明不能证明交互行为。
截图不支持时标为未捕获，不影响已测样式的真实性。

## 元素与样式

共用 assets/probe.js 只读采集 DOM、计算样式、伪元素与可访问样式声明。
它枚举有布局盒的元素，包括视口外元素，默认最多 600 项。
采样截断时增加 maxElements 或定向分段，不能声称完整。
选择器是本次快照坐标，不保证网站改版后稳定。
跨域样式表读失败和计算样式读失败分别记录。
探针不读取输入值、Cookie、存储、内联脚本或令牌。
导航候选过滤敏感查询参数；仅采用户授权页面。

观察颜色/渐变/透明度、排版组合/字体特性、padding/gap、
圆角/阴影/网格/最大宽度及实际存在的动效声明。
CSS 变量名属于源声明，新起的 Token 名称属于解释。
计算样式 px 是当前条件解析值，不能据此否认源站使用 rem/clamp。
Canvas/WebGL 图形不是 DOM 样式，保留截图并说明无法逐元素测量。

## 质量与恢复

HTTP 200 仍需核对标题和主内容；挑战页不是目标页面。
API 成功与目标页成功分别检查。
快照独立落盘后写 index，普通重试复用成功快照。
其他 URL 的已有计划拒绝覆盖；范围修改由 Agent 审核。
只有截图时可写推断说明，不伪造实测 Token。
未验证交互、缺失字体、采样限制和失败统一写 coverage。
